# Malaysian LIAM Pricing Reference

`reference/Medical_Dataset_Malaysia_LIAM_Price_Ranges.csv` is retained as a published Malaysian private-healthcare pricing reference.

The file contains procedure-level P25, typical, and P75 bill amounts in MYR, source PDF pages, and the publisher URL. It is not patient-level training data and is never merged into the NSS or US models. Rows marked `Insufficient credible data` remain unavailable rather than receiving fabricated values.
